بيانات فودافون — مشروع واجهة أندرويد أولية

المحتويات:
- main.py: واجهة عربية بالأحمر والأسود.
- requirements.txt: مكتبة Kivy.
- buildozer.spec: إعدادات البناء.

مهم:
هذه نسخة واجهة أولية فقط؛ لم يتم ربطها بخدمات تسجيل دخول فودافون أو جمع بيانات الحساب.
لا تدخل كلمة مرور حقيقية في نسخة تجريبية. لاستخدام بيانات الحساب، استعمل تكاملاً رسمياً ومصرحاً به، ولا تخزن كلمات المرور أو رموز الدخول.

لإنشاء APK عادةً يلزم Buildozer في بيئة Linux أو خدمة بناء موثوقة تدعم Buildozer؛ لا يمكن إنتاج APK نهائي من ملف Python وحده على أندرويد دون بيئة بناء مناسبة.
